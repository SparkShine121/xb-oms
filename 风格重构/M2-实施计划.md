# M2 组件层与公共组件抽取 实施计划（风格重构）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立 `src/components/` 公共组件层（页头 / 搜索工具栏 / 表格容器 / 分页 / 空状态），把 15 个 PC 页面迁移到公共组件上，删掉各页重复复制的 `.toolbar/.toolbar-right/.pager` 样式块（落地错题集"同类 UI 优先全局化"的教训），并补齐 loading/empty 两态与 M1 遗留的输入框问题。

**Architecture:** 五个细粒度、可组合的展示型组件（Q1-a 决策）。`DataTable` 拥有卡片容器 + `el-table` + loading + 空状态接线；`SearchToolbar` 只负责筛选/操作两槽的 flex 布局；`PageHeader` 承载标题 + 说明 + 主按钮；`AppPagination` 封装分页的固定配置与 `update:page` / `change` 事件。页面只写业务：数据加载、列定义、抽屉/弹窗。组件用各自 scoped 样式；全局 `style.css` 保持"只有令牌 + EP/Vant 映射"。

**Tech Stack:** Vue 3 `<script setup>` + TypeScript + Element Plus + `@phosphor-icons/vue`（图标，M2 首次引入）；测试用 vitest（组件测试用 jsdom + `@vue/test-utils`，两者均已在 devDependencies）。

## Global Constraints

- **令牌**：只用规范 §1 的令牌（`--panel/--panel2/--panel3/--line/--line2/--txt/--mut/--dim/--lime*/--r-*/--shadow-*`），**不得新增硬编码色值**；禁止纯白 `#fff`、禁止纯黑阴影
- **图标**：一律 `@phosphor-icons/vue`（`Ph*` 前缀导出），禁止手绘 SVG 图标；weight 约定：导航/常规 `regular`、按钮 `bold`、状态/空状态 `duotone`
- **交互行为零改动**：迁移是模板重构，不得改动任何 API 调用、权限判断、表单校验、路由跳转、`useBulkDelete` 用法
- **路由/文案零改动**：菜单标签、页面路由、按钮文案保持原样
- **组件目录**：`frontend/src/components/`（新建）；组件样式写在各自 `<style scoped>`；**不往 `style.css` 加组件样式**
- **可访问性**：空状态的图标为装饰性（`aria-hidden`），操作按钮必须是真实 `el-button`
- **提交规范**：每个 Task 独立 commit，前缀 `style(restyle-m2):` 或 `feat(restyle-m2):`
- **分支**：从 `dev` 拉 `feature/restyle-m2-components`（见 Task 0）
- **本期不做**（Q2 决策）：error 态（加载失败 + 重试）不做，沿用全局 toast；骨架屏不做，列表 loading 沿用 `v-loading`

```css
  box-shadow: 0 0 0 1px var(--lime-text) inset, 0 0 0 3px var(--lime-tint);
}
.el-input__inner:focus-visible,
.el-select__input:focus-visible {
  outline: none;
}
```

```vue
<script setup lang="ts">
withDefaults(defineProps<{
  page: number
  pageSize: number
  total: number
  pageSizes?: number[]
}>(), {
  pageSizes: () => [10, 20, 50, 100],
})

const emit = defineEmits<{
  'update:page': [value: number]
  'update:pageSize': [value: number]
  change: []
}>()

function onCurrentChange(value: number) {
  emit('update:page', value)
  emit('change')
}

function onSizeChange(value: number) {
  emit('update:pageSize', value)
  emit('update:page', 1)
  emit('change')
}
</script>

    class="app-pagination"
    background
    :current-page="page"
    :page-size="pageSize"
    :total="total"
    :page-sizes="pageSizes"
    layout="total, sizes, prev, pager, next, jumper"
    @current-change="onCurrentChange"
    @size-change="onSizeChange"
  />
</template>

<style scoped>
.app-pagination {
  margin-top: 12px;
  justify-content: flex-end;
}
</style>
```

```ts
// @vitest-environment node
// 迁移不变量：视图层不得再复制工具栏/分页样式块（错题集 2026-09-07「同类 UI 优先全局化」）
import { describe, expect, it } from 'vitest'

const views = import.meta.glob('../views/**/*.vue', { query: '?raw', import: 'default', eager: true }) as Record<string, string>

describe('组件迁移不变量', () => {
  it('没有页面同时复制 .toolbar 与 .toolbar-right 样式块', () => {
    const offenders = Object.entries(views)
      .filter(([, src]) => /\.toolbar\s*\{/.test(src) && /\.toolbar-right\s*\{/.test(src))
      .map(([path]) => path)
    expect(offenders).toEqual([])
  })

  it('列表页不再自带 .pager 样式块', () => {
    const offenders = Object.entries(views)
      .filter(([, src]) => /\.pager\s*\{/.test(src))
      .map(([path]) => path)
    expect(offenders).toEqual([])
  })
})
```
