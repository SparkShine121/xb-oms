### Task 1: 全局 prefers-reduced-motion 降级（规范 §6 强制项）

**Files:**
- Modify: `frontend/src/style.css`（文件末尾追加一段）
- Test: `frontend/src/tests/designTokens.test.ts`（追加 describe）

**Interfaces:**
- Produces: 全站 animation/transition 在 reduced-motion 下压至 0.01ms 的 blanket 规则（覆盖自定义样式与 EP/Vant 内置过渡）。

- [ ] **Step 1: 写失败测试**

`designTokens.test.ts` 末尾追加：

```ts
describe('可达性：prefers-reduced-motion（规范 §6 强制项）', () => {
  it('全局降级规则存在且压平 animation/transition', () => {
    expect(css).toMatch(/@media\s*\(prefers-reduced-motion:\s*reduce\)\s*\{[\s\S]*animation-duration:\s*0\.01ms/)
    expect(css).toMatch(/@media\s*\(prefers-reduced-motion:\s*reduce\)\s*\{[\s\S]*transition-duration:\s*0\.01ms/)
    expect(css).toMatch(/@media\s*\(prefers-reduced-motion:\s*reduce\)\s*\{[\s\S]*animation-iteration-count:\s*1/)
  })
})
```

- [ ] **Step 2: 跑测试确认失败**

Run: 单文件 → FAIL（style.css 无该 media 块）。

- [ ] **Step 3: 实现（style.css 末尾追加）**

```css
/* ============================================================
 * 可达性：prefers-reduced-motion（规范 §6 强制项）
 * 用户系统开启"减弱动态效果"时，压平全站动画/过渡（含 EP/Vant 内置）；
 * 保留瞬时状态切换，无无限循环动画。
 * ============================================================ */
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

- [ ] **Step 4: 跑测试确认通过 + 全量**

Run: 单文件 PASS；全量 `npx vitest run --test-timeout=30000` PASS（77 例）。

- [ ] **Step 5: 提交**

```bash
git add frontend/src/style.css frontend/src/tests/designTokens.test.ts
git commit -m "feat(restyle-m6): 全局 prefers-reduced-motion 降级（规范 §6 强制项）"
```


```ts
const NAMED_COLORS = 'black|white|red|green|blue|yellow|orange|purple|pink|gray|grey|cyan|magenta|silver|gold|teal|navy|olive|lime|aqua|fuchsia|crimson|indigo|violet|tomato|salmon|coral'
if (new RegExp(`#[0-9a-fA-F]{3,8}\\b|\\brgba?\\(|\\bhsla?\\(|:\\s*(?:${NAMED_COLORS})\\b`).test(s)) offenders.push(path)
```

同时：
1. `const pcSources` 改名 `const allViewSources`（describe 内两处引用同步改：非空守卫与 for 循环）
2. `allViewSources` 的构造在三个 glob 后追加 App.vue（在 layouts glob 之后合并）：

```ts
  ...(import.meta.glob('../App.vue', { query: '?raw', import: 'default', eager: true }) as Record<string, string>),
```
