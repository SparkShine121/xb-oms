# M4 图表层实施计划（Dashboard KPI 指标行 + 6 ECharts 浅色主题 + 硬编码收尾 + 双门禁）

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 仪表盘 4 tab 视觉达标——KPI 区改无卡指标行、6 个 ECharts 统一浅色主题、残留硬编码色清零，并立两道确定性门禁（主题一致性 + PC 端硬编码色扫描）。

**Architecture:** 新建纯常量模块 `frontend/src/analytics/chartTheme.ts`（无 echarts 依赖，可被 node 测试直接 import），Dashboard.vue 以 `echarts.registerTheme` 一次性注册、6 图 `init(el, THEME_NAME)` 启用；门禁进 `designTokens.test.ts`（与既有令牌锁定同文件）。不改任何交互、路由、文案。

**Tech Stack:** Vue 3 + TS + Element Plus + ECharts 6（canvas 渲染，CSS 变量在 canvas 内无效——主题必须写具体色值常量）+ Vitest。

## Global Constraints（每个任务隐含遵守）

- **文案零改动**：`数据分析`、KPI 标签 `订单总数 / 总销售额（USD） / 总毛利（USD）`、图表 title（`月度销售/毛利趋势` 等）、表格列头全部原样保留。
- **令牌唯一依据**：《风格重构/风格拆解清单.md》§1；颜色值以 `style.css` 为准，`designTokens.test.ts` 锁定。
- **禁止 import element-plus 完整包**；style.css 中 `.el-*` 覆盖必须双类（铁律 2）——本模块不改 style.css，勿新增 `.el-*` 单类规则。
- **chartTheme.ts 色值一律小写**且与令牌字面量逐字符一致（含逗号后空格：`rgba(17, 19, 23, 0.08)`），因为测试用 `token()`（已 lowercase）逐值比对。
- 测试命令（ARM 需长超时）：`cd frontend && npx vitest run src/tests/designTokens.test.ts --test-timeout=30000`；全量 `npx vitest run --test-timeout=30000`；收尾 `npm run build`。
- 分支：从 `dev` 拉 `feature/restyle-m4`，每任务独立 commit（结尾 `Co-Authored-By: Claude Sonnet 5 <noreply@anthropic.com>`），完成后合并回 `dev`。
- 本模块**不改** style.css、不改 el-dialog→el-drawer（grilling Q3-b）、不动后端。

```ts
// ECharts 浅色主题常量（规范《风格拆解清单.md》§7 仪表盘）。
// ECharts 为 canvas 渲染，CSS 变量在 canvas 中无效——色值必须与 style.css 令牌逐值一致，
// 由 designTokens.test.ts「ECharts 浅色主题」describe 锁定（改令牌时同步此处，测试会红）。
// 双轨制：序列色是文字型强调，lime 档用深橄榄 --lime-text（非 --lime 填充色）。
export const THEME_NAME = 'xbb-light'

/** 序列色 4 档：lime-text / info / success / warning（规范 §7） */
export const CHART_COLORS = ['#5b7600', '#1d4ed8', '#17803d', '#c2410c']

export const XBB_LIGHT_THEME = {
  backgroundColor: 'transparent',
  color: CHART_COLORS,
  title: {
    textStyle: { color: '#17191e', fontSize: 14, fontWeight: 600 },
  },
  legend: {
    textStyle: { color: '#5b616b', fontSize: 12 },
  },
  categoryAxis: {
    axisLine: { lineStyle: { color: 'rgba(17, 19, 23, 0.08)' } },
    axisTick: { show: false },
    axisLabel: { color: '#5b616b' },
    splitLine: { show: false },
  },
  valueAxis: {
    axisLine: { show: false },
    axisTick: { show: false },
    axisLabel: { color: '#5b616b' },
    splitLine: { lineStyle: { color: 'rgba(17, 19, 23, 0.08)' } },
  },
  tooltip: {
    backgroundColor: '#fcfcfd',
    borderColor: 'rgba(17, 19, 23, 0.14)',
    borderWidth: 1,
    padding: [8, 12],
    textStyle: { color: '#17191e', fontSize: 12.5 },
    extraCssText: 'box-shadow: 0 12px 32px -8px rgba(20, 24, 32, 0.14); border-radius: 12px;',
  },
}
```

注意：`backgroundColor: 'transparent'` 与 `color` 不走 token() 比对（canvas 特殊值 + 引用自身），其余逐值锁定。

const pcSources: Record<string, string> = {
  ...(import.meta.glob('../views/**/*.vue', { query: '?raw', import: 'default', eager: true }) as Record<string, string>),

末尾追加 describe：

```ts
describe('门禁：PC 端零硬编码色（M6 全站扫描的 PC 前置卡）', () => {
  it('views/components/layouts（排除 views/m/，移动端属 M5）源码无硬编码色', () => {
    const offenders: string[] = []
    for (const [path, src] of Object.entries(pcSources)) {
      if (path.includes('/views/m/')) continue
      if (HARDCODED_COLOR_ALLOW.some(a => path.includes(a))) continue
      const s = src
        .replace(/<!--[\s\S]*?-->/g, '')   // HTML 注释
        .replace(/\/\*[\s\S]*?\*\//g, '')  // CSS 块注释
        .replace(/\/\/[^\n]*/g, '')        // 行注释
      if (/#[0-9a-fA-F]{3,8}\b/.test(s) || /\brgba?\(/.test(s)) offenders.push(path)
    }
    expect(offenders).toEqual([])
  })
})
```
