# 风格重构设计规范（浅色版）

> **本规范是重构的唯一执行依据。** 目标站（fuu9qs9u.qwenwork.host，深色展示型 demo）的原始提取值见附录 A 对照表，完整源码见 `源码快照.html`，审查过程见 `设计审查报告.md`。
> 转译方向：目标站设计语言的 **浅色化 + ERP 化**，已并入 taste-skill / redesign-skill 审查的全部 P0/P1 修订（处置表见附录 B）。
> 设计参数：`DESIGN_VARIANCE 3-4` · `MOTION_INTENSITY 3-4` · `VISUAL_DENSITY 7 (Cockpit)`；模式：**Redesign-Overhaul**（视觉换新，IA / 路由 / 导航标签 / 文案不动）。

---

## 0. 三条铁律

1. **学层次与克制，不学低密度与展示元素**：目标站是给人看气质的 demo（密度约 3-4），本 ERP 是给人干活的（密度 7）。视觉语言照搬，间距密度重算。
2. **走官方系统的主题 API**：Element Plus（PC）/ Vant（移动）就是我们的官方设计系统。主题一律走其 CSS 变量；类覆盖最小化、有据可查；**不手搓替代组件**。
3. **可达性强制**：正文对比 ≥ 4.5:1、聚焦指示与承载语义的控件边界 ≥ 3:1、focus 可见、`prefers-reduced-motion` 降级。本规范所有颜色值已按 AA 选型，实现时不得随意替换。

## 1. 设计令牌（浅色版）

### 1.1 表面与文字

| 令牌 | 值 | 用途 |
|---|---|---|
| `--canvas` | `#F1F2F4` | 应用画布（三面板之间的缝隙底色） |
| `--panel` | `#FCFCFD` | 面板 / 卡片（**off-white，禁纯白 #FFF**） |
| `--panel2` | `#F5F6F8` | 嵌套层：输入框底、tabs 容器、表头、看板泳道 |
| `--panel3` | `#ECEDF0` | 再嵌套：chips 底、次级按钮、激活底 |
| `--line` | `rgba(17,19,23,.08)` | 默认描边 |
| `--line2` | `rgba(17,19,23,.14)` | 输入框描边 / hover 加深 / 浮层描边 |
| `--txt` | `#17191E` | 主文字（近黑，**非纯黑**）≈17:1 |
| `--mut` | `#5B616B` | 次要文字（说明、label、图标）≈6.1:1 |
| `--dim` | `#666C75` | 弱文字（meta、时间戳）≈5.2:1，**AA 达标，勿再调浅** |

### 1.2 强调色（lime 家族，全站唯一强调色）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--lime` | `#CBF74E` | 主按钮填充、logo 底、进度条、强调块 |
| `--lime-ink` | `#15170A` | lime 底上的文字/图标（近黑） |
| `--lime-text` | `#5B7600` | **文字型强调**：链接、激活态文字、focus 环 ≈5.1:1 |
| `--lime-deep` | `#4A6100` | 深底上的强调文字：菜单/导航激活态（对 `--panel3` ≈6.0:1；`--lime-text` 在该底上仅 4.44 不达 AA） |
| `--lime-tint` | `rgba(163,209,26,.14)` | 强调类 chips / 选中行底色 |
| `--lime-hover` | `#BCEB3A` | 主按钮 hover |
| `--lime-active` | `#ADDC28` | 主按钮 active |

> **双轨制（本规范的核心机制）**：lime 是浅色，做"填充"极佳（配 ink 文字对比极高），做"文字"不可读。因此凡文字/图标型强调一律用 `--lime-text`，凡填充型强调一律 `--lime` + `--lime-ink`。§8 的 EP/Vant 映射按此拆成两条。

### 1.3 语义色（仅状态语义，禁装饰用途）

| 令牌 | 值 | tint（12% 底） | 用途 |
|---|---|---|---|
| `--success` | `#17803D` | `rgba(23,128,61,.12)` | 成功、已完成、正向 |
| `--warning` | `#C2410C` | `rgba(194,65,12,.12)` | 逾期、告警、负载 >90%（继承目标站橙色语义） |
| `--danger` | `#C0352B` | `rgba(192,53,43,.12)` | 错误、危险操作 |
| `--info` | `#1D4ED8` | `rgba(29,78,216,.10)` | 仅信息提示（**蓝色降级**：P1 优先级等改用中性灰阶表示） |

### 1.4 阴影（带底色调，禁纯黑）

```css
--shadow-card:    0 1px 2px rgba(20,24,32,.05), 0 1px 3px rgba(20,24,32,.04);
--shadow-pop:     0 12px 32px -8px rgba(20,24,32,.14);
--shadow-overlay: 0 24px 64px -12px rgba(20,24,32,.22);
```

### 1.5 圆角（形状一致性锁定，不得混用）

`--r-frame: 32px`（三大面板、登录卡）→ `--r-card: 24px`（卡片、表格容器、弹窗）→ `--r-in: 16px`（内部块：文件行、日程行、看板卡）→ `--r-ctl: 12px`（按钮、输入框、分段容器）→ `--r-nav: 14px`（侧栏导航项、日历格）→ `--r-sm: 10px`（小按钮）→ `999px`（chips、徽标、开关、Toast）。

### 1.6 间距（密度适配后，**非照抄目标站**）

| 场景 | 值 | 对比目标站 |
|---|---|---|
| 画布 padding / 面板间 gap | 12px | 目标站 14（收紧） |
| 内容区 view padding | 22px 24px | 目标站 26/28（收紧） |
| 卡片内距 | 16px | 目标站 20（收紧） |
| 网格 gap | 14px | 目标站 16（收紧） |
| 表格 | 垂直内距 8px（水平沿用 EP 默认 12px）；表头 12.5px·600；正文 13px | 目标站表格本来就紧（9px 12px/12px），密度原样采用 |
| 行内元素 gap | 8-12px | 同 |

### 1.7 缓动与时长

唯一曲线 `--ease: cubic-bezier(.22,1,.36,1)`；时长 0.15s（微反馈）/ 0.22s（hover）/ 0.3s（浮层入场）。

## 2. 字体排印

- **字体栈**：`-apple-system, BlinkMacSystemFont, 'PingFang SC', 'HarmonyOS Sans SC', 'Microsoft YaHei', system-ui, sans-serif`（不引入 webfont；**可选升级**：金额/数量/日期场景可自托管 IBM Plex Mono 数字，二期再定）。
- **行高**：正文 13px / **1.65**（中文行高 1.6-1.7，不用目标站的 1.55）。
- **数字**：全局 `.num` = `font-variant-numeric: tabular-nums` + `letter-spacing: -.01em`，所有金额/数量/百分比/日期必须套。
- **字重**：400 / 500 / 600 / 700（新增 500 做中间层次）。

| 字号 | 字重 | 用途 |
|---|---|---|
| 22-24px | 700 | 仪表盘 KPI 数字（目标站 30px → 降为 22-24） |
| 18-20px | 600 | 页面标题 h2（紧字距 -.01em） |
| 14px | 600 | 卡片标题 h3 |
| 13px | 400/500 | 正文基准、表格正文 |
| 12.5px | 400/600 | 页头说明 `.sub`、表单 label；表格表头（600） |
| 12px | 400 | 次要信息（时间戳、注脚等） |
| 11.5px | 400/500 | chips、meta |
| 11px | 400 | 最弱信息（时间戳、注脚） |

标题加 `text-wrap: balance` 防孤字；大字号紧字距（-.01 ~ -.02em）。

## 6. 动效与可达性（强制项）

- 微动效清单：按钮 active scale(.97)；卡片 hover 上浮 2-3px + 边线加深；侧栏项 hover 渐入；flyout 入场 0.22s；进度条宽度过渡 0.7s；页面切换 fade-in（opacity + translateY 6px）。
- **只动 `transform` / `opacity`**（进度条宽度为数据可视化的合理例外）。
- **`@media (prefers-reduced-motion: reduce)` 必须关闭**非必要动画（保留 ≤0.1s 的 opacity 微变）；不得有无限循环动画。
- **focus-visible 可见环**：全站交互元素统一 `2px solid var(--lime-text)` + `outline-offset: 2px`；Tab 序完整；flyout 支持 Esc 关闭。
- 对比度自检：本规范 §1 全部颜色值已按 AA 选型；实现中新引入的任何颜色必须过 AA 才可用。

## 7. 页面适配要点

- **仪表盘（analytics）**：KPI 区从"3 张等高卡"改为 **4-6 列无卡指标行**（数字 22-24px/700 + 1px 分隔线，不套卡片）；6 个 ECharts 统一浅色主题（轴线 `--line`、文字 `--mut`、序列色 `[--lime-text, --info, --success, --warning]`、背景透明）；保留现有 4 个 tab 结构。
- **列表页（11 个）**：统一为「页头（标题 + 说明 + 操作区）→ 搜索工具栏 → 表格 → 分页」公共组件；这是 M2 抽公共组件的主要服务对象。
- **详情页 / 表单页**：表单默认走抽屉；抽屉与移动端用 **label 上置**，宽表单保留现有右对齐 label（中文 ERP 惯例，空间效率高；已评审豁免 taste-skill 的 label 上置规则，但**禁止 placeholder 充当 label**）。
- **跟单工作台**：状态节点用语义色 + Phosphor 图标，节点连线用 `--line`；不引入看板拖拽等新功能。
- **移动端（Vant）**：主题变量按 §8.2 映射；首页 banner 改 lime 系浅色渐变；tabbar 10 项与顺序不变；仅换肤，不改结构。

## 8. Element Plus / Vant 映射

### 8.1 Element Plus（浅色）

  /* 边框 */

  --el-border-color-hover:var(--line2);
  /* 圆角与阴影 */

  --el-box-shadow:var(--shadow-pop); --el-box-shadow-dark:var(--shadow-overlay);
  /* primary 双轨制：文字型用深橄榄（可读），填充型按钮单独覆盖 */

  --el-color-primary-light-3:#7C9A1F; --el-color-primary-light-5:#A8BE66;
  --el-color-primary-light-7:#D3E0B0; --el-color-primary-light-8:#E5EDD0; --el-color-primary-light-9:#F2F6E6;

  --el-color-danger:var(--danger); --el-color-error:var(--danger); --el-color-info:var(--info);
}
