> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 移动端 views/m/ 的 43 处硬编码色全部令牌化（10 文件）、"工厂结算" tab 在 375px 不再换行、M4 的 PC 硬编码色门禁扩展到全量 views/components/layouts。

**Tech Stack:** Vue 3 + Vant 4 + Vitest（raw 源码扫描测试，node 环境）。

### Task 1: tabbar 换行修复（"工厂结算" @375px）

**Files:**
- Modify: `frontend/src/layouts/MobileLayout.vue`（scoped style，现 22-30 行）
- Test: `frontend/src/tests/designTokens.test.ts`（追加 describe）

**Interfaces:**
- Produces: MobileLayout 含 `.van-tabbar-item__text` 的 10.5px + nowrap 规则（Task 5 门禁扫描 layouts/ 时该文件不得新增硬编码色）。

- [ ] **Step 1: 写失败测试**

`designTokens.test.ts` 顶部加：

```ts
const mobileLayoutSrc = readFileSync(new URL('../layouts/MobileLayout.vue', import.meta.url), 'utf8')
```

末尾追加：

```ts
describe('移动端 tabbar（M5）', () => {
  it('tabbar 标签 10.5px + 不换行（"工厂结算"4 字标签在 375px 不折行）', () => {
    expect(mobileLayoutSrc).toContain('van-tabbar-item__text')
    expect(mobileLayoutSrc).toMatch(/van-tabbar-item__text[\s\S]{0,200}?font-size:\s*10\.5px/)
    expect(mobileLayoutSrc).toMatch(/van-tabbar-item__text[\s\S]{0,200}?white-space:\s*nowrap/)
  })
})
```

- [ ] **Step 2: 跑测试确认失败**

Run: `cd frontend && npx vitest run src/tests/designTokens.test.ts --test-timeout=30000`
Expected: FAIL——新用例红（MobileLayout 尚无该规则）。

- [ ] **Step 3: 实现**

`MobileLayout.vue` 的 `<style scoped>` 内（现有规则之后）追加：

```css
/* 10 个 tab 在 375px 时每项仅 37.5px，"工厂结算"4 字标签默认 12px 会折行；
   缩至 10.5px + nowrap（走查确认无相邻重叠，重叠则降 9.5px 兜底） */
:deep(.van-tabbar-item__text) {
  font-size: 10.5px;
  letter-spacing: -0.01em;
  white-space: nowrap;
}
```

- [ ] **Step 4: 跑测试确认通过 + 全量**

Run: 单文件 → PASS；`npx vitest run --test-timeout=30000` → 全量 PASS（76 例）。

- [ ] **Step 5: 提交**

```bash

git commit -m "fix(restyle-m5): tabbar 标签 10.5px + nowrap（工厂结算 375px 不折行）"
```
