## 模块 6：轻财务（`apps/finance/`）

### 新模型：PaymentIn

| 字段 | 类型 | 说明 |
|---|---|---|
| order | FK→Order, related_name='payments_in' | 关联订单 |
| amount_usd | DecimalField(14,2) | 本次到账金额 |
| payment_date | DateField | 到账日期 |
| installment | IntegerField default 1 | 第几期 |
| note | TextField blank | 备注 |
| created_at/updated_at | | 时间戳 |

### 收支流水（纯聚合 API）

`GET /api/finance/ledger/?start_date=&end_date=&type=`

聚合四类数据为统一流水列表：

| 类型 | 来源 | 方向 |
|---|---|---|
| income_receipt | PaymentIn | 收入 + |
| expense_factory | FactoryPaymentRecord | 支出 − |
| expense_logistics | Logistics.cost | 支出 − |
| expense_service_fee | Order.service_fee_usd | 支出 − |

### 导出 Excel

`GET /api/finance/export/?start_date=&end_date=` → openpyxl 导出 xlsx。

### 前端

- 回款登记页（PaymentIn CRUD）
- 收支流水页（聚合列表 + 筛选 + 导出按钮）
- OrderDetail 加回款区块
- PC + 移动端完整

## 模块 7：数据分析（`apps/analytics/`）

不建新模型。后端 4 个聚合 API，前端 ECharts 渲染。

### 聚合 API

| 端点 | 维度 | 返回 |
|---|---|---|
| `GET /api/analytics/sales/` | 时间/业务员/客户 | 订单数/总金额/总毛利/毛利率 |
| `GET /api/analytics/factory-summary/` | 时间/工厂 | 应付/已付/未付 |
| `GET /api/analytics/tracking-summary/` | 时间/节点 | 各节点分布数/平均停留时长 |
| `GET /api/analytics/overview/` | 年度总览 | 月度销售额/毛利趋势 |

### 前端（仅 PC）

`views/analytics/Dashboard.vue`：ECharts 页面，4 个 tab 切换。

## 模块 8：系统管理（`apps/system_mgmt/`）

### 审批流

**ApprovalRequest 模型**：

| 字段 | 类型 |
|---|---|
| approval_type | CharField choices(settlement/payment/order_change/logistics) |
| target_id | IntegerField |
| target_model | CharField |
| status | CharField default 'pending' (pending/approved/rejected) |
| submitted_by | FK→User |
| reviewed_by | FK→User null |
| note | TextField blank |
| created_at/updated_at | |

**集成**：
- FactoryPayment/FactoryPaymentRecord/Order/Logistics 加 `is_approved = BooleanField(default=True)`
- 新建时 is_approved=False + 创建 ApprovalRequest
- admin 通过 → is_approved=True；驳回 → 可改后重提
- 存量数据 is_approved=True 不迁移

### 操作日志

**OperationLog 模型** + Django middleware 自动拦截写请求记录。

### 备份恢复

- BackupRecord 模型（file_path/file_size/created_at/trigger）
- 审批通过后自动 SQLite .backup → backups/
- 手动备份按钮 + 备份列表下载 + 滚动保留 1000 份

### 前端（仅 PC）

- ApprovalList.vue：待审批列表 + 通过/驳回
- OperationLogList.vue：操作日志查询
- BackupManage.vue：备份管理
