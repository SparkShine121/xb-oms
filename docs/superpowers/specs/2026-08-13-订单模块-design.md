## 3. 数据模型

### 3.1 Order（订单主表，`apps/orders/models.py`）

全字段映射阿里订单级 + 系统字段。

| 字段 | 类型 | 说明 |
|---|---|---|
| order_no | CharField unique | 订单号（阿里订单名称 E 列） |
| ali_status | CharField | 阿里状态原值 |
| tracking_status | CharField | 系统跟单状态（接单/排产/生产中/质检/发货/签收/结算/回款/已取消） |
| order_date | DateField, null | 订单日期（C 列） |
| customer | FK→Customer, null | 关联客户（按联系人名匹配） |
| salesman | FK→User, null | 业务员（按 customer.salesman 自动） |
| tracker | FK→User, null | 跟单员（按 customer.tracker 自动，可手动改） |
| amount_usd | DecimalField | 订单金额（I 列，USD） |
| freight / insurance / surcharge | DecimalField | 运费/物流保险费/附加费用（F/G/H） |
| service_fee_usd | DecimalField | 交易服务费（J，USD） |
| transport_cost | DecimalField | 运输成本（K） |
| carrier / logistics_method / tracking_no | CharField | 承运商/物流方式/单号（L/M/N） |
| remark | TextField | 备注（O） |
| is_cancelled | BooleanField default False | 异常订单标记（阿里状态=交易失败/已退款） |
| order_profit_usd | DecimalField | 订单毛利（系统自动算） |
| created_at/updated_at | DateTimeField | 时间戳 |

### 3.2 OrderItem（订单产品行）

一订单 N 行，全字段映射阿里产品级。

| 字段 | 类型 | 说明 |
|---|---|---|
| order | FK→Order, related_name='items', on_delete=CASCADE | 所属订单 |
| seq | IntegerField | 序号（P） |
| product | FK→Product, null | 关联产品（按 product_no 匹配） |
| factory | FK→Factory, null | 关联工厂（按供应商 name/alias 匹配） |
| model / product_no / spec | CharField/TextField | 型号/产品编号/规格（S/Z/T） |
| qty | IntegerField | 数量（R） |
| unit_price | DecimalField | 单价（U，USD） |
| subtotal | DecimalField | 金额小计（V，USD） |
| cost_price | DecimalField | 含税成本价（W，CNY） |
| profit_usd | DecimalField | 产品毛利（系统算） |
| profit_rate | DecimalField | 毛利率（系统算） |
| factory_payment_id | IntegerField, null | 预留工厂结算关联（后续改 FK） |
| created_at/updated_at | DateTimeField | 时间戳 |

### 3.3 Customer.tracker（修改 `apps/basic_info/models.py`）

`tracker = FK→User, null, blank, SET_NULL, related_name='tracked_customers'`（对称 salesman，客户↔跟单员映射）。生成 migration。

### 3.4 ExchangeRate（汇率配置，`apps/orders/models.py`）

| 字段 | 类型 | 说明 |
|---|---|---|
| currency_pair | CharField default 'USD/CNY' | 货币对 |
| rate | DecimalField | 汇率（1 USD = rate CNY） |
| effective_date | DateField | 生效日期 |
| created_at/updated_at | DateTimeField | 时间戳 |

取当期汇率：`effective_date <= 订单日期` 的最新一条；订单无日期时取最新。管理员维护。

### 3.5 毛利计算（系统自动，导入/保存时触发）

- 产品毛利(USD) = `subtotal − cost_price × qty ÷ exchange_rate`
- 毛利率 = `profit_usd ÷ subtotal`
- 订单毛利(USD) = `Σ items.profit_usd − freight − insurance − surcharge − service_fee_usd`
- 不存阿里原毛利值（X/Y 列），系统重算
- 汇率变更暂不自动重算历史订单（后续可加 action）

## 4. 订单导入

### 4.1 流程（`apps/orders/importers.py`）

```
上传 Excel → openpyxl 解析 → 合并单元格展开（主表字段下放到产品行）
  → 逐订单 upsert：
      1. 按订单号(order_no)查找
      2. 关联基础信息：
         - customer: 按联系人名(D列)匹配 Customer.name → FK + 自动 salesman/tracker
         - product: 按产品编号(Z列)匹配 Product.product_no → FK
         - factory: 按供应商名(Q列)匹配 Factory.name 或 Factory.alias → FK
         - 未匹配: FK=null, 记入 unmatched 清单（不阻塞）
      3. 状态映射: ali_status → tracking_status；交易失败/已退款 → is_cancelled=True
      4. 跟单员: 新订单填 customer.tracker；已存在订单若 tracker 为空才填（手动派单不被覆盖）
      5. 毛利计算: 每产品行 profit_usd/profit_rate + 订单 order_profit_usd（当期汇率）
      6. 产品行: 整组替换（删旧建新）；本模块 factory_payment_id 未用，无锁定需求
  → 返回 {success_count, fail_count, failures, unmatched}
```

### 4.2 阿里状态映射表

| 阿里状态 | tracking_status | is_cancelled |
|---|---|---|
| 待确认 | 接单 | False |
| 待发货 | 排产 | False |
| 已发货 | 发货 | False |
| 交易成功 | 签收 | False |
| 交易失败 | 已取消 | True |
| 已退款 | 已取消 | True |

### 4.3 upsert 更新规则（重复导入）

- **主表可变字段**更新：amount_usd/freight/insurance/surcharge/service_fee_usd/transport_cost/carrier/logistics_method/tracking_no/remark/ali_status/tracking_status/order_date
- **锁定不覆盖**：tracker（已有值则保留手动派单）；is_cancelled 按阿里状态重算；order_profit_usd 重算更新
- **产品行整组替换**：删旧建新；factory_payment_id 本模块都为 null，无保留需求；结构变更记入结果提示，不阻塞

### 4.4 关联匹配容错

- customer：精确匹配 Customer.name；未匹配尝试去空格/大小写；仍不匹配记入 unmatched
- factory：先精确匹配 Factory.name，再匹配 Factory.alias；都未匹配记入 unmatched
- product：精确匹配 Product.product_no；未匹配记入 unmatched

### 4.5 导入结果返回

```json
{
  "success_count": 10,
  "fail_count": 1,
  "failures": [{"row": 15, "reason": "订单号为空"}],
  "unmatched": {
    "customers": [{"row": 3, "name": "吴芳"}],
    "products": [{"row": 4, "product_no": "JJ0520290"}],
    "factories": [{"row": 5, "name": "正丁"}]
  }
}
```

前端弹窗：成功数 + 失败明细表 + 未匹配清单（提示去基础信息补建）。

## 5. API + 权限

### 5.1 端点（前缀 `/api/orders/`）

| 资源 | 端点 | 说明 |
|---|---|---|
| Order | CRUD | `/orders/orders/`、`/orders/orders/{id}/` |
| Order | `POST /orders/orders/import/` | 批量导入 |
| Order | `GET /orders/orders/import-template/` | 下载模板 |
| Order | `POST /orders/orders/{id}/set-tracker/` | 派单（仅 admin） |
| ExchangeRate | CRUD | `/orders/exchange-rates/`（仅 admin） |

- OrderViewSet 继承 BaseModelViewSet；OrderItem 嵌套于 OrderSerializer（create/update 同步产品行，update 整组替换）
- 列表：分页、搜索（order_no/customer__name）、筛选（tracking_status/salesman/tracker/is_cancelled）、排序

### 5.2 OrderSerializer

- 嵌套 OrderItemSerializer（many=True）：create 同步创建产品行；update 产品行整组替换
- 暴露 customer_name/salesman_name/tracker_name（只读）
- create/update 后调 `calc_order_profit(order)` 重算产品行 + 订单毛利

### 5.3 权限

**数据可见范围**（get_queryset 按角色过滤）：

| 角色 | 可见订单 |
|---|---|
| admin / finance | 全部 |
| salesman（非 admin/finance） | customer__salesman = request.user |
| tracker（非 admin/finance） | tracker = request.user |
| 同时 salesman + tracker | 并集 Q(customer__salesman=user) \| Q(tracker=user) |

**操作权限**（自定义 OrderPermission）：

| 操作 | admin | salesman | tracker | finance |
|---|---|---|---|---|
| 查看 | 全部 | 自己客户 | 派给自己 | 全部 |
| 导入 | ✓ | ✓ | — | — |
| 新增 | ✓ | ✓ | — | — |
| 编辑 | ✓ | 自己客户订单 | 派给自己订单 | — |
| 删除 | ✓ | — | — | — |
| 派单(set-tracker) | ✓ | — | — | — |

- OrderPermission.has_permission：import/create 要求 admin 或 salesman
- OrderPermission.has_object_permission：update 按"自己客户/派给自己"；destroy 仅 admin
- set-tracker action 仅 admin
- ExchangeRateViewSet 仅 admin
