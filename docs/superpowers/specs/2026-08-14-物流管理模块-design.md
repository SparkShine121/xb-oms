## 1. 数据模型（`apps/logistics/models.py`）

### Logistics

| 字段 | 类型 | 说明 |
|---|---|---|
| order | FK→Order, on_delete=CASCADE, related_name='shipments' | 所属订单（一订单多次发货 = 多行） |
| seq | IntegerField | 第几次发货（save 时自动 = 同订单已有条数+1） |
| domestic_carrier | FK→LogisticsProvider, null, on_delete=SET_NULL | 国内段承运商 |
| intl_method | FK→LogisticsProvider, null, on_delete=SET_NULL | 国际段物流方式 |
| tracking_no | CharField(128) blank | 物流单号 |
| cost | DecimalField(14,2) default 0 | 物流费 |
| cost_currency | CharField(8) default 'CNY' | 币种（CNY/USD） |
| payer | CharField(16) default 'company' | 归属（customer/company/factory） |
| note | TextField blank | 备注 |
| created_at/updated_at | | 时间戳 |

seq 自动递增：创建时 `seq = order.shipments.count() + 1`。

## 2. API + 权限

| 端点 | 方法 | 说明 |
|---|---|---|
| `/logistics/shipments/` | CRUD | 物流单列表/详情/创建/编辑/删除 |

### LogisticsPermission

| 操作 | admin | salesman | tracker | finance |
|---|---|---|---|---|
| 查看 | 全部 | 自己客户订单 | 派给自己订单 | 全部 |
| 新增/编辑 | ✓ | — | 派给自己订单 | — |
| 删除 | ✓ | — | — | — |

数据范围通过 `order__customer__salesman` / `order__tracker` 过滤。

## 4. 关键规则

- 一物流单仅对应一订单（FK 单向）
- 两段物流关联 LogisticsProvider（按 type 区分 domestic/international）
- 费用币种每条记录独立（默认 CNY，支持 USD）
- payer 三选一：customer/company/factory，默认 company
- OrderDetail 展示物流区块但**不自动推进**跟单节点（解耦）
