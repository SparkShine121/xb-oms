## 1. 数据模型（`apps/factory_payment/models.py`）

### FactoryPayment

| 字段 | 类型 | 说明 |
|---|---|---|
| order_item | OneToOne→OrderItem, related_name='factory_payment' | 所属产品行（一个产品行一个结算单） |
| factory | FK→Factory, related_name='factory_payments' | 工厂（冗余存，按工厂查询） |
| amount_cny | DecimalField(14,2) | 应付货款（默认 qty×cost_price，可手动改） |
| paid_amount | DecimalField(14,2) default 0 | 已付（Record 累计） |
| status | CharField(16) | 未结/部分结/已结（save 时自动算） |
| note | TextField blank | 备注 |
| created_at/updated_at | | 时间戳 |

### FactoryPaymentRecord

| 字段 | 类型 | 说明 |
|---|---|---|
| factory_payment | FK→FactoryPayment, related_name='records' | 所属结算单 |
| amount | DecimalField(14,2) | 本次付款 |
| payment_date | DateField | 付款日期 |
| note | TextField blank | 备注 |
| created_at/updated_at | | 时间戳 |

### status 自动计算（save）

```python
def save(self, *args, **kwargs):
    if self.paid_amount >= self.amount_cny and self.amount_cny > 0:
        self.status = '已结'
    elif self.paid_amount > 0:
        self.status = '部分结'
    else:
        self.status = '未结'
    super().save(*args, **kwargs)
```

### 修改 `apps/orders/models.py`

删除 `OrderItem.factory_payment_id = IntegerField(null=True, blank=True)`（migration remove field）。FactoryPayment OneToOne→OrderItem 通过 related_name='factory_payment' 反查。

## 2. API + 权限

### API（前缀 `/api/factory-payment/`）

| 端点 | 方法 | 说明 |
|---|---|---|
| `/payments/` | CRUD | FactoryPayment 列表/详情/创建/编辑/删除 |
| `/records/` | CRUD | FactoryPaymentRecord 列表/创建/删除（付款登记） |
| `/orders/{order_id}/generate/` | POST | 一键生成：为订单所有有 factory 的产品行批量创建 FactoryPayment |
| `/statement/` | GET | 工厂对账单：factory + start_date + end_date 筛选 + 汇总 |

### 权限（`FactoryPaymentPermission`）

| 操作 | admin | salesman | tracker | finance |
|---|---|---|---|---|
| 查看结算单/对账 | 全部 | 自己客户订单 | 派给自己订单 | 全部 |
| 登记结算单（create/update） | ✓ | — | — | ✓ |
| 付款登记（Record create） | ✓ | — | — | ✓ |
| 一键生成（generate） | ✓ | — | — | ✓ |
| 删除结算单/付款 | ✓ | — | — | — |

### 数据范围（get_queryset）

FactoryPayment 通过 `order_item__order` 关联：
- admin/finance：全部
- salesman：`order_item__order__customer__salesman=request.user`
- tracker：`order_item__order__tracker=request.user`

### 一键生成流程

```
POST /orders/{order_id}/generate/
  → 取订单所有有 factory 的 OrderItem（factory__isnull=False）
  → 跳过已有 FactoryPayment 的产品行（OneToOne 已存在）
  → 为每个无结算单的产品行创建 FactoryPayment（amount=qty×cost_price, factory=item.factory）
  → 返回 {created_count, skipped_count}
```

### 付款登记流程

```
POST /records/（factory_payment_id + amount + payment_date）
  → 创建 FactoryPaymentRecord
  → 累计更新 FactoryPayment.paid_amount += amount
  → FactoryPayment.save() 自动重算 status
```

### 对账单

```
GET /statement/?factory=1&start_date=2026-08-01&end_date=2026-08-31
  → 按工厂 + payment_date 范围筛选 FactoryPayment
  → 返回 {total_amount, total_paid, total_unpaid, payments: [...]}
```
