> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付轻财务（PaymentIn + 收支流水 + 导出）、数据分析（4 个 ECharts 仪表盘）、系统管理（审批流 + 操作日志 + 备份恢复）。

**Tech Stack:** Python 3.13 + Django 5.1 + DRF + SQLite + openpyxl + pytest；Vue3 + Vite + TS + Element Plus + Vant + Pinia + axios + ECharts + Vitest。implementer 用 sonnet，reviewer 用 fable。
