# BUG-SIM-022 修复方案与操作日志 · 汇率功能批（含 011 遗留待办清账）

- 日期：2026-10-14 ｜ 基线：dev `44628b3` ｜ 分支：`feature/bug-sim-022-exchange-rate`
- 决策（grilling 确认）：Q1:a 全员可读仅 admin 可写（AdminWriteOthersReadOnly）；Q2:a 保存/删除汇率时自动重算受影响订单；Q3:a 「基础信息」组新页"汇率"

## 实现

1. **022 后端**：`ExchangeRateViewSet.permission_classes` → `[IsAuthenticated, AdminWriteOthersReadOnly]`（GET 全员、写仅 admin）
2. **自动重算**（011 待办）：`perform_create/update/destroy` 后重算受影响订单——`order_date >= effective_date` 或 `order_date 为空` 的全部订单逐单 `calc_order_profit`；update 且日期变更时取新旧日期的较小者作影响起点
3. **022 前端**：新页 `views/basic_info/ExchangeRateManage.vue`（PageHeader+DataTable 五件套模式；列表币种对/汇率/生效日期；admin 显示新增/编辑/删除按钮，对话框表单）；路由 `/basic-info/rates`；menuConfig 基础信息组加"汇率"；复用既有 4 个 API 封装（原死代码激活）

## 测试（TDD 先红）
