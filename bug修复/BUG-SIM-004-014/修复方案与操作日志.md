## 全系统归属权威语义（本批确立）

| 路径 | salesman | tracker |
|---|---|---|
| Excel 导入（**仅 admin**） | customer.salesman 自动分配 | customer.tracker 自动映射（非 tracker 角色静默不填） |
| UI 建单（非 admin） | 强制=建单人；所选客户必须是自己客户（否则 400） | 忽略 payload（置空待派单） |
| UI 建单（admin） | 可任意指定 | 可任意指定（但必须 tracker 角色，Q3:a） |
| set-tracker 派单（**仅 admin**） | — | 目标必须 tracker 角色（400） |
| 编辑改派（仅 admin，已有） | 不变 | 不变（同校验） |

## 实现

1. `OrderPermission.has_permission` 重构：`import_data` → 仅 admin；finance 的 `set_tracker` → False（其余不变）
2. `OrderSerializer`：
   - create 路径非 admin：salesman=建单人、tracker 剔除、customer.salesman_id != user.id → 400"只能为自己客户的订单录入"
   - 新增 `validate_tracker`：任何路径提供的 tracker 必须 tracker 角色（覆盖 admin 建单/编辑）
3. `set_tracker` action：目标用户必须 tracker 角色 → 400"目标用户必须为跟单员（tracker）角色"
4. `importers.py` tracker 自动映射加角色静默校验（与 029 孤儿字段现状兼容）
5. 前端 `OrderList.vue`：`canImport` 收紧为 `isAdmin`（业务员隐藏导入按钮）
