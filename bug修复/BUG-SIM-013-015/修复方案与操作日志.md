2. **015**：
   - `generate_by_order`：取消订单的明细逐条进 skipped（200，决策静默语义）
   - `FactoryPaymentSerializer.validate`（create）：明细属已取消订单 → 400"已取消订单不可新建结算"
   - 付款记录不加限制（对存量结算清偿合法）
3. **Q3:a**：`FactorySummaryView` qs 排除取消单（`order_item__order__is_cancelled=False`）；`statement` 对账单不动（回归锁锁定）
4. **027**：`OrderList.vue` 操作列加"取消"按钮（`isAdmin` 且未取消；二次确认 → PATCH is_cancelled=true → reload）
